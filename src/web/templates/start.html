Quick setup

Three steps to get pensabot running

Create the bot, add your OpenAI key, then sign up to link Telegram from the dashboard.

Step 1

Create a Telegram Bot

Create your bot with BotFather, copy the token, and keep it ready for your app configuration.

  1. Open @BotFather in Telegram.
  2. Run /newbot and follow the bot name + username prompts.
  3. Save the token in your environment.
TELEGRAM_BOT_TOKEN=123456:telegram-token
{% if telegram_bot_username %}

Current bot username configured for links: @{{ telegram_bot_username }}

{% endif %}
Step 2

Create an OpenAI API Key

Generate an API key for the model calls that classify, store, and search the messages you send to your bot.

  1. Create a key in your OpenAI account.
  2. Add it to the same environment file or deployment secret set.
  3. Restart the app so the backend picks up the key.
OPENAI_API_KEY=sk-...
Step 3

Sign up and link Telegram

Create your account to open the dashboard, generate a Telegram start link, and connect your chat in one click.

Sign up Already have an account

After sign in, you will be sent directly to /dashboard.
